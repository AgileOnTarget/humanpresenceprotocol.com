Support for the HPP Chrome Gateway

This page is help for the Human Presence Protocol Chrome extension and the public test pages at humanpresenceprotocol.com/Dev/Chrome. The website receives only true or false. It does not receive biometrics, keys, or a verifier session token.

What you need

  • The Human Presence Protocol Chrome extension
  • The HPP iPhone app from the App Store
  • An iPhone with Face ID or Touch ID set up

Test page: humanpresenceprotocol.com/Dev/Chrome

How to verify

  1. Install the Chrome extension.
  2. Open the test page and click Verify Human.
  3. A QR code appears in Chrome. There should be no SIMULATION label on a live HTTPS page.
  4. In the HPP iPhone app, scan that QR and complete Face ID or Touch ID.
  5. Chrome should show that you have been verified as a human.

Troubleshooting

Verify Human does nothing, or says the extension is missing

Install or enable the extension, then reload the tab. The page cannot complete a live check without the extension.

The QR will not scan

Allow camera access for the HPP app in iOS Settings. Hold the phone about 6 to 12 inches from the screen. If the code is small, enlarge the Chrome window.

Face ID or Touch ID does not complete

Confirm biometrics in iOS Settings. If the check fails, scan a fresh QR from the website and try again.

The phone succeeds but the Chrome tab stays on the test page

Keep the tab open after you scan. After Face ID, Chrome should move to the success page. If it does not, reload the extension, hard-refresh the tab, and run Verify Human again.
